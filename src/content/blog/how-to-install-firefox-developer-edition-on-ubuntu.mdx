While most Linux software comes through package managers, Firefox Developer Edition is distributed as a .tar.bz2 file, making its installation a bit different. This guide will walk you through the setup process, which you can also use as a reference for installing similar tools on Linux.

<Note>
  This guide was tested on Ubuntu-based distributions. While the general steps
  remain similar, some commands and paths might differ on other distributions.
  I'll note distribution-specific differences where relevant.
</Note>

## Download the Software

First, download the software from the [official website](https://www.mozilla.org/en-US/firefox/developer/). After the download is complete you will have a <FileCode>.tar.bz2</FileCode> archive.

<Success>
  Make sure to download the version that matches your system architecture
  (32-bit or 64-bit).
</Success>

## Extract the Archive

Now we need to decompress the archive and move it to a global location. For most distributions, run:

```bash isTerminal
sudo tar xjvf firefox-*.tar.bz2 -C /opt
```

<Warning>
  Distribution-specific notes: - On Fedora/RHEL, you might need to create the
  /opt directory first: <InlineCode>sudo mkdir -p /opt</InlineCode>- On
  Arch-based systems, consider using <InlineCode>/usr/local</InlineCode> instead
  of <InlineCode>/opt</InlineCode>- Some distributions might require different
  permissions for /opt - The above command should be run from the same directory
  that contains the archive
</Warning>

### Command Explanation

Let's break down the command we're using:

1. Using <InlineCode>sudo</InlineCode> <small>(SuperUser DO)</small> to get administrative privileges for accessing the <InlineCode>/opt</InlineCode> directory
2. Using the <InlineCode>tar</InlineCode> command with these options:

- <InlineCode>-x</InlineCode>: Extract the archive
- <InlineCode>-j</InlineCode>: Handle <FileCode>.bz2</FileCode> compression
- <InlineCode>-v</InlineCode>: Show verbose output (list files)
- <InlineCode>-f</InlineCode>: Specify the archive file
- <InlineCode>-C</InlineCode>: Set the target directory

Now if you run <InlineCode>/opt/firefox/firefox</InlineCode> you will be able to launch Firefox Developer. However, we can make it much easier to access with a few additional steps.

## Create a Symlink

First, let's create a [Symlink](https://en.wikipedia.org/wiki/Symbolic_link) for the Firefox script and make it globally available in the terminal:

```bash isTerminal
sudo ln -s /opt/firefox/firefox /usr/local/bin/firefox-dev
```

This will allow you to start Firefox Developer Edition by simply typing <InlineCode>firefox-dev</InlineCode> in your terminal.

## Create a Desktop Entry

The desktop entry location might vary by distribution:

- For most distributions: <InlineCode>/usr/share/applications/</InlineCode>
- For some distributions: <InlineCode>~/.local/share/applications/</InlineCode>

```bash isTerminal
# For system-wide installation (requires sudo):
sudo nano /usr/share/applications/Firefox-Developer-Edition.desktop

# Alternative for user-specific installation (no sudo needed):
mkdir -p ~/.local/share/applications
nano ~/.local/share/applications/Firefox-Developer-Edition.desktop
```

Copy and paste the following into the file:

```plaintext filename="Firefox-Developer-Edition.desktop" showLineNumbers
[Desktop Entry]
Version=1.0
Name=Firefox Web Browser
Comment=Browse the World Wide Web
GenericName=Web Browser
Keywords=Internet;WWW;Browser;Web;Explorer
Exec=firefox-dev %u
Terminal=false
X-MultipleArgs=false
Type=Application
Icon=/opt/firefox/browser/chrome/icons/default/default128.png
Categories=GNOME;GTK;Network;WebBrowser;Utility;
MimeType=text/html;text/xml;application/xhtml+xml;application/xml;application/rss+xml;application/rdf+xml;image/gif;image/jpeg;image/png;x-scheme-handler/http;x-scheme-handler/https;x-scheme-handler/ftp;x-scheme-handler/chrome;video/webm;application/x-xpinstall;
StartupNotify=true
```

To save the changes:

1. Press <Kbd>Ctrl</Kbd> + <Kbd>S</Kbd> to save
2. Press <Kbd>Ctrl</Kbd> + <Kbd>X</Kbd> to exit

You should now see the Firefox Developer Edition icon in your application menu:

![Firefox Developer Edition appearing in the Ubuntu application menu](/src/images/how-to-install-firefox-developer-edition-on-ubuntu/application-menu.png)

<Note>
  If the desktop icon isn't showing properly, add this line to the end of the
  desktop file: ```plaintext StartupWMClass=firefox-aurora ```
</Note>

## Troubleshooting

### Common Distribution-Specific Issues

1. **Permission Issues**

- Debian/Ubuntu: You might need to run <InlineCode>sudo chown -R $USER:$USER /opt/firefox</InlineCode>
- SELinux-enabled systems (Fedora/RHEL): You might need to set correct contexts

2. **Missing Dependencies**

- Ubuntu/Debian: Run <InlineCode>sudo apt-get install libgtk-3-0</InlineCode>
- Fedora: Run <InlineCode>sudo dnf install gtk3</InlineCode>
- Arch: Run <InlineCode>sudo pacman -S gtk3</InlineCode>

3. **Icon Not Showing**

- Some distributions might need to rebuild their icon cache:

```bash
sudo update-desktop-database
sudo gtk-update-icon-cache
```
